# ♻️ EcoSort AI

### AI-Powered Waste Segregation Assistant

EcoSort AI is a sustainability-focused web prototype designed to help users identify everyday waste and understand appropriate disposal categories.

The project is aligned with **UN Sustainable Development Goal 12 – Responsible Consumption and Production**.

## 🌱 Problem

Improper waste segregation is a common challenge. People may be unsure whether everyday items such as food waste, plastic bottles, cardboard, batteries, and electronic products should be placed in wet, dry, recyclable, or hazardous waste categories.

Incorrect segregation can contaminate recyclable materials and increase environmental impact.

## 💡 Solution

EcoSort AI provides an interactive waste-segregation assistant where users can:

* Upload an image of a waste item
* Describe the item using text
* Receive a waste category
* View a recommended disposal action
* View a confidence indication
* Understand responsible AI considerations

## 🤖 AI Approach

The project demonstrates an **AI-assisted prompt workflow** for waste identification and classification.

The AI workflow is designed to provide:

1. Identified Item
2. Waste Category
3. Recommended Action
4. Reason
5. Confidence Level

The prompt also instructs the AI to communicate uncertainty and recommend checking local waste-management guidelines.

The current web prototype provides an interactive classification experience using JavaScript, while the AI component is demonstrated separately through the AI-assisted prompt workflow.

## 🛡️ Responsible AI

EcoSort AI is designed as a decision-support tool rather than a replacement for official waste-management guidance.

Users are encouraged to:

* Verify uncertain results
* Check local waste-management rules
* Avoid placing hazardous materials in normal waste
* Avoid sharing personal information through the system
